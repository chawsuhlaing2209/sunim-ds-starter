# governance/ — Advisor

**Level here: Advisor**, whatever the agent's level elsewhere — including 🚀 DevOps,
which is Autonomous everywhere else. This folder records what each agent is allowed to
do. An agent that can write here can raise its own level, and no verifier downstream
would notice.

## May do here
- Read `fleet.md`, `operating-model.md` and `decisions.md`
- Open a PR proposing a change, with the evidence for it
- Append a new entry to `decisions.md` in a PR — never edit or delete an existing one

## Must escalate to a human
- Merging anything into this folder
- Any change to a level, a ceiling, a promotion criterion, or a kill switch
- Confirming a `proposed at` entry. That is the orchestrator's word, not an agent's

## Kill switch for this path
Branch protection on `main` requiring review — ⚠️ not verified as in place. Today the
real control is that every change arrives as a PR and a human merges it.
