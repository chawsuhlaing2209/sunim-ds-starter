# build/ — Observer

**Level here: Observer**, whatever the agent's level elsewhere. Everything under
`build/` is generated by Style Dictionary. An edit here survives until the next build
and the thing it disagreed with is still wrong.

## May do here
- Read `build/tokens/css/tokens.css` to confirm a token resolves
- Run `npm run build:tokens` to regenerate it

## Must escalate to a human
- Any hand edit, including a one-character fix
- A value that is wrong in the build — the fault is in Figma or in
  `style-dictionary.config.js`, and neither is fixed here

## Kill switch for this path
`build/` is gitignored and regenerated, so deleting it costs nothing. To prevent an
edit: a `deny` rule on `Edit(build/**)`. ⚠️ Not in place today.
